# A100 80G 显存速查表

> ⭐ 写代码前先估算显存，避免训到一半 OOM。
>
> 估算公式：参数量 × 精度 × 倍数
> - 推理：1×（参数）
> - 训练：4×（参数 + 梯度 + Adam moments）
> - 加 activation 约 + 30~50%

---

## 一、精度对照

| 精度 | bytes / 参数 | 备注 |
|------|------------|------|
| fp32 | 4 | 默认，最准 |
| bf16 | 2 | A100 推荐，数值范围与 fp32 相近 |
| fp16 | 2 | 易溢出（loss=nan），慎用 |
| int8 | 1 | bitsandbytes 量化 |
| int4 | 0.5 | QLoRA 用 |

## 四、显存优化组合拳

### 第 1 级：bf16
```python
model = model.to(torch.bfloat16)
# 立省 50%
```

### 第 2 级：冻结 backbone
```python
for p in model.backbone.parameters():
    p.requires_grad = False
# 梯度和 Adam 状态都不算 backbone
# 立省 75%（只算 head 的训练显存）
```

### 第 3 级：Gradient Accumulation
```python
optim.zero_grad()
for i, batch in enumerate(loader):
    loss = model(batch) / accum_steps
    loss.backward()
    if (i + 1) % accum_steps == 0:
        optim.step()
        optim.zero_grad()
# 等效 batch_size × accum_steps，但只占 1 倍显存
```

### 第 4 级：Gradient Checkpointing
```python
model.gradient_checkpointing_enable()
# 省 30~50% 显存，慢 30%
```

### 第 5 级：LoRA / QLoRA
```python
from peft import LoraConfig, get_peft_model
config = LoraConfig(r=16, lora_alpha=32, target_modules=["q_proj","v_proj"])
model = get_peft_model(model, config)
# 7B 模型可训练参数从 7B → 4M，省 99%
```

### 第 6 级：QLoRA (4bit)
```python
from transformers import BitsAndBytesConfig
bnb = BitsAndBytesConfig(
    load_in_4bit=True,
    bnb_4bit_compute_dtype=torch.bfloat16,
    bnb_4bit_quant_type="nf4",
    bnb_4bit_use_double_quant=True
)
model = AutoModel.from_pretrained(path, quantization_config=bnb)
# 7B 模型 14G → 4G
```

## 六、OOM 应急 5 步

1. **batch 减半** → 最快
2. **bf16** if not already
3. **冻结 backbone** if not already
4. **gradient_checkpointing_enable()**
5. **关 attention cache**：`model.config.use_cache = False`（训练时本来就该关）

5 步后还 OOM → 用 LoRA / QLoRA。

---

## 七、推理 vs 训练显存对比表

| 阶段 | 显存内容 | 倍数 |
|------|---------|------|
| 加载模型 | 参数 × dtype | 1× |
| 前向推理 | + activations | 1.2 ~ 2× |
| 反向训练 | + 梯度 | 2× |
| Adam 优化器 | + 2 个 moment（fp32） | 4× |
| 全部加起来 | + activation 峰值 | 5 ~ 6× |

> **经验值**：训练显存 ≈ 模型 fp32 大小 × 4 ~ 6
> 例：Qwen3-7B → 7B × 4 bytes × 5 = 140 GB ❌ A100 80G 装不下
> 必须 bf16 + 冻结/LoRA
