# 国内镜像配置速查

> ⭐ 不能上外网 → 所有下载走国内镜像。

---

## 一、HuggingFace 镜像（hf-mirror.com）

### 一次性配置
```bash
export HF_ENDPOINT=https://hf-mirror.com
```

### 持久化到 ~/.bashrc
```bash
echo 'export HF_ENDPOINT=https://hf-mirror.com' >> ~/.bashrc
source ~/.bashrc
```

### Python 内运行时设置
```python
import os
os.environ['HF_ENDPOINT'] = 'https://hf-mirror.com'
# 必须在 import transformers 之前
from transformers import AutoModel
```

### 验证
```bash
echo $HF_ENDPOINT
# 应该输出 https://hf-mirror.com

python -c "
from huggingface_hub import HfApi
api = HfApi()
print(api.endpoint)
"
# 应该输出 https://hf-mirror.com
```

### 下载测试
```bash
# 这条命令应该能下载（如果开发机能访问 hf-mirror.com）
huggingface-cli download bert-base-uncased --local-dir /tmp/bert-test
```

⚠️ **科研实训环境**：所有模型已经预下载在 `/vepfs-readonly/problemN/...`，**实际上不需要联网**。HF mirror 只是当 transformers 内部 check 时不报错。

## 二、pip 镜像

### 临时使用
```bash
pip install torch --index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

### 永久配置 ⭐
```bash
mkdir -p ~/.pip
cat > ~/.pip/pip.conf <<EOF
[global]
index-url = https://pypi.tuna.tsinghua.edu.cn/simple
extra-index-url =
    https://mirrors.aliyun.com/pypi/simple/
    https://pypi.mirrors.ustc.edu.cn/simple/
trusted-host =
    pypi.tuna.tsinghua.edu.cn
    mirrors.aliyun.com
    pypi.mirrors.ustc.edu.cn
timeout = 120
EOF
```

### 验证
```bash
pip config list
# 应输出 global.index-url='https://pypi.tuna.tsinghua.edu.cn/simple'

pip install --dry-run requests
# 看 "Looking in indexes:" 是否包含 tuna
```

### 三大主流镜像
| 镜像 | URL | 备注 |
|------|-----|------|
| 清华 | `https://pypi.tuna.tsinghua.edu.cn/simple` | ⭐ 默认 |
| 阿里 | `https://mirrors.aliyun.com/pypi/simple/` | 备用 |
| 中科大 | `https://pypi.mirrors.ustc.edu.cn/simple/` | 备用 |
| 豆瓣 | `https://pypi.douban.com/simple/` | 较慢，仅备用 |

### 临时换源
```bash
pip install <pkg> -i https://mirrors.aliyun.com/pypi/simple/ --trusted-host mirrors.aliyun.com
```

```yaml
  - https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/main
```

## 五、Git 镜像（克隆 HF repo）


## 八、综合诊断脚本

```bash
#!/bin/bash
# diagnose-mirror.sh

echo "=== 网络诊断 ==="

echo "--- 外网（应该不通）---"
curl -s --max-time 5 https://www.google.com > /dev/null && echo "❌ 居然能上 Google！" || echo "✅ Google 不通（符合预期）"

echo "--- HF mirror ---"
curl -s --max-time 10 https://hf-mirror.com > /dev/null && echo "✅ hf-mirror.com OK" || echo "❌ hf-mirror.com 不通"

echo "--- pypi 清华 ---"
curl -s --max-time 10 https://pypi.tuna.tsinghua.edu.cn > /dev/null && echo "✅ 清华 pypi OK" || echo "❌ 清华 pypi 不通"

echo "--- pypi 阿里 ---"
curl -s --max-time 10 https://mirrors.aliyun.com > /dev/null && echo "✅ 阿里 mirror OK" || echo "❌ 阿里 mirror 不通"

echo "--- 当前环境变量 ---"
env | grep -E "HF_|HTTP" || echo "  无相关环境变量"

echo "--- pip 配置 ---"
pip config list 2>&1

echo "--- conda 配置 ---"
[ -f ~/.condarc ] && cat ~/.condarc || echo "无 ~/.condarc"
```

## 九、常见错误

| 错误 | 修复 |
|------|------|
| `ConnectionError: HTTPSConnectionPool(host='huggingface.co'...)` | 加 `export HF_ENDPOINT=https://hf-mirror.com` |
| `pip install` 超时 | 换源 `-i https://mirrors.aliyun.com/pypi/simple/` |
| pip SSL 错误 | 加 `--trusted-host pypi.tuna.tsinghua.edu.cn` |
| HF model not found（hf-mirror 缺这个模型） | 用 ModelScope |
| `huggingface_hub.errors.LocalEntryNotFoundError` | 模型已在本地但没找到，检查 cache_dir 或直接给绝对路径 |
| 下载到一半中断 | `huggingface-cli download --resume-download` |

## 十、考场版「一键修好镜像」

把这段复制粘贴到终端：

```bash
# 1. HF mirror
echo 'export HF_ENDPOINT=https://hf-mirror.com' >> ~/.bashrc
export HF_ENDPOINT=https://hf-mirror.com

# 2. pip 清华
mkdir -p ~/.pip && cat > ~/.pip/pip.conf <<'EOF'
[global]
index-url = https://pypi.tuna.tsinghua.edu.cn/simple
trusted-host = pypi.tuna.tsinghua.edu.cn
timeout = 120
EOF

# 3. 验证
echo "HF: $HF_ENDPOINT"
pip config list

echo "✅ 镜像配置完成"
```

⭐ 通常 `01-bootstrap.sh` 已经做了这些。
