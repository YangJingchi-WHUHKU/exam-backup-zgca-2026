## 二、各题详细格式

### Q1: Flow Matching ZGC

**目录结构**：
```
/vepfs/<user>/problem1/
├── flow_zgc.py            ⭐ 必须可 python flow_zgc.py 直接跑
├── README.md              ⭐ 说明单模型设计 +8 分
└── results/
    ├── zgc.jpg            ⭐ 4×4 网格图，展示 Z→G→C
    ├── zgc.json           ⭐ 三字段
    └── zgc_chamfer.json   ⭐ CD 指标
```

**`zgc.json` 格式**：
```json
{
  "start": [[x1, y1], [x2, y2], ...],   // T=0，从分布 Z 采样的 2000 个点
  "mid":   [[x1, y1], [x2, y2], ...],   // T=1，应接近 G
  "end":   [[x1, y1], [x2, y2], ...]    // T=2，应接近 C
}
```

**`zgc_chamfer.json` 格式**：
```json
{
  "start_vs_Z": 0.012,    // 应 ≈ 0（起点采样）
  "mid_vs_G":   0.034,    // 期望 < 0.05
  "end_vs_C":   0.041     // 期望 < 0.05
}
```

**易错点**：
- ⚠️ `mid` 和 `end` 是 **Euler 积分到 T=1 / T=2 时的点云**，不是训练数据
- ⚠️ `zgc.jpg` 应该是 4×4 网格，**展示中间时间步**的演变（不只是 3 张图）
- ❌ 用两个独立模型分段拼接 → 失去 8 分（必须 README 说清楚单模型）

### Q2: VQ-VAE + Transformer

**目录结构**：
```
/vepfs/<user>/problem2/VQVAE/
├── train_vqvae.py
├── train_vqvae_prior.py
├── checkpoints/
│   ├── vqvae.pt            ⭐ 步骤 1 产物
│   └── vqvae_prior.pt      ⭐ 步骤 2/3 产物
├── README.md
└── train.log
```

**`vqvae.pt` 保存内容**（建议）：
```python
torch.save({
    'model_state_dict': model.state_dict(),
    'config': {'hidden_dim': 128, 'embedding_dim': 64, 'num_embeddings': 512},
    'epoch': epoch,
}, 'checkpoints/vqvae.pt')
```

**易错点**：
- ❌ **采样不能用 argmax**（FID 会爆炸），必须用 `torch.multinomial`（带 temperature/Top-K/Top-P）
- ❌ `complete()` 输出的**上半部分必须与原图一致**（不是 Transformer 生成的）
- ❌ Causal mask 错位 → loss 看着对但实际泄露未来 token
- ⚠️ Codebook collapse：训练时观察 codebook 使用率（活跃 token 数 / `num_embeddings`）

### Q3 (DNA): test_output.csv

**文件位置**：`/vepfs/<user>/problem3/test_output.csv`

**严格格式**：
```csv
label1,label2
3.5267,0.8734
2.1543,1.2876
0.9876,0.5432
...
```

**易错点**：
- ❌ 表头必须是 `label1,label2`（不是 `developmental,housekeeping`）
- ❌ 顺序**严格按测试集**（不能 shuffle）
- ❌ 数据缺失不要填 `nan`，预测一个合理默认值
- ⚠️ 浮点精度建议 4 位小数

**完整提交包**：
```
/vepfs/<user>/problem3/
├── test_output.csv         ⭐ 主结果
├── train.py                ⭐ 训练代码
├── README.md
├── train.log               ⭐ epoch / loss / 双 pearson
└── checkpoints/best.pt     可选
```

### Q3' (蛋白质): test_result.json

**文件位置**：`/vepfs/<user>/problem2/test_result.json`（秋季题在 problem2）

**严格格式**：
```json
{
    "name": "杨镜池",
    "test_result": {
        "protein_001": ["MKTVRQERLKSIVRILERSKEPVSGAQ...", 1],
        "protein_002": ["KALTARQQEVDLIRDHISQTGMPPTRA...", 0],
        "protein_003": ["MNSLKDVLLTFSKIGG...", 1]
    }
}
```

**易错点**：
- ❌ key 名是 `test_result` **不是 `test_results`**（少打/多打 s 都 0 分）
- ❌ value 是 `[sequence, int_label]`，**label 是整数 0/1，不是字符串**
- ❌ `protein_xxx` key 必须来自 dataset 元数据，不能自编序号
- ⚠️ JSON 必须 UTF-8、无 BOM
- ⚠️ 用 `json.dump(..., ensure_ascii=False, indent=2)` 输出可读格式

**验证**：
```python
import json
with open('test_result.json') as f:
    d = json.load(f)
assert 'name' in d and 'test_result' in d
for k, v in d['test_result'].items():
    assert isinstance(v, list) and len(v) == 2
    assert isinstance(v[0], str) and isinstance(v[1], int)
    assert v[1] in (0, 1)
print(f"✅ OK, {len(d['test_result'])} proteins")
```

### Q4: RAG / Agentic

**目录结构**：
```
/vepfs/<user>/problem4/
├── code/                       ⭐ 修改后的完整项目源码
│   ├── build_index.py
│   ├── run_agent.py
│   └── rag/
│       ├── agent/agent.py
│       └── retrieval/hybrid_store.py
├── prediction.txt              ⭐ 50 行答案
├── report.md                   ⭐ 架构图 + 复现步骤
└── logs/                       ⭐ JSONL 日志
    └── run_agent_<timestamp>.jsonl
```

**`prediction.txt` 格式**（**每行一答案，纯文本**）：
```
Yes
American
1985
unknown
The Eiffel Tower
...
```

**易错点**：
- ❌ 必须 **50 行**，多一行少一行都不行
- ❌ 每行只含**答案文本**，不要 "Answer: " 前缀
- ❌ 不确定的题输出 `unknown`，**不要瞎猜**（评分会扣得更多）
- ❌ 答案不要带标点（除非答案本身是句子）

**JSONL 日志必含字段**：
```json
{
  "qid": 1,
  "question": "Were Scott Derrickson and Ed Wood of the same nationality?",
  "round": 1,
  "retrieval_query": "Scott Derrickson nationality",
  "topk_docs": [{"doc_id": 3421, "score": 0.87, "text": "Scott Derrickson (born July 16, 1966) is an American director..."}],
  "prompt": "...full prompt sent to LLM...",
  "llm_response": "...raw response...",
  "final_answer": "Yes"
}
```

### RL / GRPO 类（如果出 RL 题）

**典型提交**：
```
/vepfs/<user>/problemN/
├── train.py                ⭐ 训练代码
├── train.log               ⭐ 完整日志
├── predictions.jsonl       ⭐ 测试推理结果
├── README.md               ⭐ 奖励设计说明
├── checkpoints/
│   └── final/              LoRA adapter / 全模型
└── logs/
    └── reward_components.csv   多奖励独立曲线
```

**`predictions.jsonl` 每行**：
```json
{"id": 0, "prompt": "...", "response": "...", "reward": 0.8}
```

**易错点**：
- ⚠️ 奖励设计是评分重点 → README 必须讲清楚每个 reward 的设计动机
- ⚠️ 多奖励组合：在 train.log 中**独立展示**每个 reward 的曲线，不只是 total reward
- ❌ vLLM colocate 模式忘记设 → 训练超慢

## 四、最终提交前 checklist（必做）

- [ ] 所有文件在 `/vepfs/<user>/problemN/` 下，不在 `/vepfs-readonly/`
- [ ] 文件名**逐字对照**题面，包括大小写、下划线、复数 s
- [ ] 主结果文件**能被脚本读取**（json.load 不报错、pd.read_csv 列数对）
- [ ] README.md 不是空的，至少 3 节
- [ ] train.log 完整（不是模板化的 3 行）
- [ ] 代码可以**重新跑通**（路径用相对路径或显式 args）
- [ ] **行数对**（RAG 50 行，CSV 与测试集行数一致）
- [ ] JSON 编码是 UTF-8 无 BOM
- [ ] 上交前**自己跑一遍 sanity check 脚本**

```python
# 通用 sanity check
import json, pandas as pd, os

# JSON 检查
for f in ['test_result.json', 'zgc.json', 'zgc_chamfer.json']:
    if os.path.exists(f):
        with open(f) as fp: json.load(fp)
        print(f"✅ {f} valid JSON")

# CSV 检查
if os.path.exists('test_output.csv'):
    df = pd.read_csv('test_output.csv')
    assert list(df.columns) == ['label1', 'label2'], f"❌ 表头错: {df.columns.tolist()}"
    print(f"✅ test_output.csv: {len(df)} rows, columns OK")

# TXT 检查
if os.path.exists('prediction.txt'):
    with open('prediction.txt') as fp:
        lines = fp.readlines()
    assert len(lines) == 50, f"❌ 行数错: {len(lines)}"
    print(f"✅ prediction.txt: 50 lines OK")
```
