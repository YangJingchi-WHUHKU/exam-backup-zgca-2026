## 一、分类指标

### Accuracy
$$\text{Acc} = \frac{\text{正确预测}}{\text{总数}} = \frac{TP+TN}{TP+TN+FP+FN}$$

```python
acc = (preds == labels).mean()
# 或 sklearn
from sklearn.metrics import accuracy_score
acc = accuracy_score(labels, preds)
```

### Precision / Recall / F1
$$\text{Precision} = \frac{TP}{TP+FP},\quad \text{Recall} = \frac{TP}{TP+FN},\quad F_1 = \frac{2 \cdot P \cdot R}{P + R}$$

```python
from sklearn.metrics import precision_score, recall_score, f1_score
p = precision_score(labels, preds, average='binary')   # or 'macro' / 'weighted'
r = recall_score(labels, preds, average='binary')
f1 = f1_score(labels, preds, average='binary')
```

### Top-K Accuracy
```python
# logits: [batch, num_classes]
topk = logits.topk(k, dim=-1).indices    # [batch, k]
correct = (topk == labels.unsqueeze(-1)).any(dim=-1)
top_k_acc = correct.float().mean().item()
```

## 二、回归指标

### MSE / RMSE / MAE
$$\text{MSE} = \frac{1}{N}\sum(\hat{y}-y)^2,\quad \text{RMSE} = \sqrt{\text{MSE}},\quad \text{MAE} = \frac{1}{N}\sum|\hat{y}-y|$$

```python
import numpy as np
mse  = np.mean((preds - labels) ** 2)
rmse = np.sqrt(mse)
mae  = np.mean(np.abs(preds - labels))
```

### Pearson 相关系数 ⭐（DNA 回归题必用）
$$r = \frac{\sum(x_i-\bar{x})(y_i-\bar{y})}{\sqrt{\sum(x_i-\bar{x})^2 \cdot \sum(y_i-\bar{y})^2}}$$

```python
# 一行 numpy
pearson = np.corrcoef(preds, labels)[0, 1]

# 或者更稳的 scipy 版
from scipy.stats import pearsonr
r, p_value = pearsonr(preds, labels)

# 多维（DNA 题双目标，各自算）
r1, _ = pearsonr(preds[:, 0], labels[:, 0])   # developmental
r2, _ = pearsonr(preds[:, 1], labels[:, 1])   # housekeeping
print(f"Pearson dev={r1:.4f}, hk={r2:.4f}, mean={(r1+r2)/2:.4f}")
```

⚠️ **警告**：preds 全是常数 → 标准差为 0 → pearson 为 nan。训练时要看 loss 不是 nan + preds 有方差。

### Spearman 相关系数
```python
from scipy.stats import spearmanr
rho, p_value = spearmanr(preds, labels)
```

## 三、生成模型指标

### Chamfer Distance ⭐（Flow Matching 题必用）
$$\text{CD}(X, Y) = \frac{1}{|X|}\sum_{x \in X}\min_{y \in Y}\|x-y\|^2 + \frac{1}{|Y|}\sum_{y \in Y}\min_{x \in X}\|y-x\|^2$$

**torch 实现**（支持 GPU）：
```python
import torch

def chamfer_distance(X, Y):
    """
    X: [N, D]  - 点云 1
    Y: [M, D]  - 点云 2
    返回: 标量（双向平均距离平方）
    """
    # 计算两两距离 [N, M]
    dist = torch.cdist(X.unsqueeze(0), Y.unsqueeze(0)).squeeze(0) ** 2
    cd_xy = dist.min(dim=1)[0].mean()    # X 到 Y
    cd_yx = dist.min(dim=0)[0].mean()    # Y 到 X
    return (cd_xy + cd_yx).item()

# 用法
cd_mid_vs_G = chamfer_distance(torch.tensor(mid_points), torch.tensor(G_points))
```

⚠️ **大点云爆显存**：N×M 距离矩阵，N=M=2000 时 = 1600 万浮点。N>5000 用 chunk 分批。

### FID（Frechet Inception Distance） ⭐（VQ-VAE 题必用）
$$\text{FID} = \|\mu_r - \mu_g\|^2 + \text{Tr}(\Sigma_r + \Sigma_g - 2(\Sigma_r \Sigma_g)^{1/2})$$

**用 pytorch-fid**：
```bash
pip install pytorch-fid
python -m pytorch_fid /path/to/real_images /path/to/generated_images
```

**编程接口**：
```python
from pytorch_fid.fid_score import calculate_fid_given_paths
fid = calculate_fid_given_paths(
    ['/path/real', '/path/gen'],
    batch_size=50,
    device='cuda',
    dims=2048   # Inception 2048 维特征
)
```

**关键要点**：
- 真实图与生成图都要 ≥ 1024 张（否则 FID 不稳）
- 图像格式：PNG 或 JPG，[0, 255] RGB
- VQ-VAE 题：先存图到磁盘再算 FID

## 四、NLP / RAG 指标

### Exact Match (EM)
```python
def exact_match(pred, gold):
    return int(pred.strip().lower() == gold.strip().lower())
em = np.mean([exact_match(p, g) for p, g in zip(preds, golds)])
```

### F1（Token-level，QA 用）
```python
def token_f1(pred, gold):
    pred_tokens = pred.lower().split()
    gold_tokens = gold.lower().split()
    common = set(pred_tokens) & set(gold_tokens)
    if not common: return 0
    p = len(common) / len(pred_tokens)
    r = len(common) / len(gold_tokens)
    return 2 * p * r / (p + r)
```

### BLEU
```python
from nltk.translate.bleu_score import sentence_bleu, SmoothingFunction
smooth = SmoothingFunction().method1
bleu = sentence_bleu([gold.split()], pred.split(), smoothing_function=smooth)
```

## 五、训练监控辅助指标

### 困惑度（Perplexity）
$$\text{PPL} = \exp(\text{CrossEntropy})$$

```python
import torch
ppl = torch.exp(loss).item()    # loss 必须是 mean over tokens
```

### Codebook 使用率（VQ-VAE 必看）
```python
# encoding_indices: [batch * H * W]，每个值是 [0, num_embeddings) 的 token id
used = torch.unique(encoding_indices).numel()
usage_rate = used / num_embeddings
print(f"Codebook usage: {used}/{num_embeddings} = {usage_rate*100:.1f}%")
# 健康值：> 50%。< 20% 表示 Codebook Collapse
```

### 梯度范数（看训练健康）
```python
total_norm = torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
# total_norm 应在 0.1 ~ 10 之间。
# > 100 → 梯度爆炸（用 grad clip）
# < 1e-4 → 梯度消失（lr 太小或冻结了）
```

## 六、易错总结表

| 指标 | 易错点 |
|------|--------|
| Pearson | preds 全相同 → nan |
| Chamfer Distance | N×M 距离矩阵爆显存 |
| FID | 图像数量 < 1024 不稳 |
| Accuracy | 类别不均衡时无意义，要看 F1 |
| BLEU | n-gram > 句子长度 → 0，要用 smoothing |
| Codebook usage | 训练时不监控就发现不了 collapse |

## 七、提交前自检脚本

```python
# 不同题用不同部分
import numpy as np
from scipy.stats import pearsonr

def check_dna_output(csv_path, n_test):
    """DNA 回归题检查"""
    import pandas as pd
    df = pd.read_csv(csv_path)
    assert list(df.columns) == ['label1', 'label2']
    assert len(df) == n_test
    assert not df.isna().any().any(), "存在 NaN"
    print(f"✅ {csv_path}: {len(df)} rows OK")

def check_rag_output(txt_path):
    """RAG 题检查"""
    with open(txt_path) as f:
        lines = [l.strip() for l in f.readlines()]
    assert len(lines) == 50, f"应该 50 行，实际 {len(lines)}"
    assert all(lines), "存在空行"
    print(f"✅ {txt_path}: 50 lines OK")

def check_flow_output(json_path):
    """Flow Matching 题检查"""
    import json
    with open(json_path) as f:
        d = json.load(f)
    for k in ['start', 'mid', 'end']:
        assert k in d, f"缺少 {k}"
        assert len(d[k]) > 100, f"{k} 点数过少"
    print(f"✅ {json_path}: 三字段 OK, 点数 {[len(d[k]) for k in ['start','mid','end']]}")
```
