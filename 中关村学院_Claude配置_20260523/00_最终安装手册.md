# Claude Code 最终安装手册（Linux 无 sudo）

> 联想 Ubuntu 笔记本上从零开始装 Claude Code + 4 个中转站
> 看到任何报错先停下来截图发我，不要继续跑

---

## 🌐 网络判断（重要）

先测试外网：

```bash
curl -I https://raw.githubusercontent.com 2>&1 | head -3
```

- 看到 `HTTP/2 200` 或 `HTTP/1.1 200` → **网通**，直接跳到 [第 1 段](#-第-1-段装-nodejs无-sudo)
- 看到 `Could not resolve` / `Connection timed out` / 卡住不动 → **网不通**，先看 [FlClash 代理方案](#-flclash-代理方案网不通时再用)

---

## 🚀 第 1 段：装 Node.js（无 sudo）

复制整段 paste 到终端：

```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
export NVM_DIR="$HOME/.nvm"
[ -s "$NVM_DIR/nvm.sh" ] && \. "$NVM_DIR/nvm.sh"
export NVM_NODEJS_ORG_MIRROR="https://npmmirror.com/mirrors/node/"
nvm install --lts
node -v
```

**成功标志**：最后一行打印 `v20.xx.x` 之类的。

---

## 🚀 第 2 段：装 Claude Code

第 1 段成功后 paste：

```bash
npm config set registry https://registry.npmmirror.com
npm install -g @anthropic-ai/claude-code
claude --version
```

**成功标志**：最后一行打印 claude 版本号（不报错）。

## 🌐 FlClash 代理方案（网不通时再用）

### 1. 给文件加可执行权限并解压

```bash
chmod +x FlClash-0.8.92-linux-amd64.AppImage
./FlClash-0.8.92-linux-amd64.AppImage --appimage-extract
cd squashfs-root
./AppRun
```

### 2. 在 FlClash 图形界面：
- 导入订阅链接（同学发的）
- 选一个节点（一般选延迟最低的）
- 打开"**系统代理**"开关
- 看清楚监听端口（通常是 `7890`）

### 3. **回到终端**设代理变量：

```bash
export HTTPS_PROXY=http://127.0.0.1:7890
export HTTP_PROXY=http://127.0.0.1:7890
```

### 4. 验证代理通了：

```bash
curl -I https://raw.githubusercontent.com
```
看到 `HTTP/2 200` 就 OK。

### 5. 然后回去跑 [第 1 段](#-第-1-段装-nodejs无-sudo)。

## 🔧 装 34 个 skill（可选）

如果 U 盘还插着：

```bash
USB=$(find /media -name "skills_全量备份" -type d 2>/dev/null | head -1)
if [ -n "$USB" ]; then
    mkdir -p ~/.config/agents/skills ~/.claude/skills
    for s in "$USB"/*/; do
        n=$(basename "$s")
        rm -rf "$HOME/.config/agents/skills/$n" "$HOME/.claude/skills/$n"
        cp -r "$s" "$HOME/.config/agents/skills/$n"
        ln -sf "$HOME/.config/agents/skills/$n" "$HOME/.claude/skills/$n"
    done
    echo "✅ skill 装好: $(ls ~/.config/agents/skills/ | wc -l) 个"
else
    echo "❌ 没找到 skills_全量备份，确认 U 盘插着"
fi
```

## 🆘 排障

### A. `curl: command not found`
试 wget：
```bash
wget -qO- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
```

### B. nvm install 卡住或失败
切到 FlClash 代理方案后重试。

### C. npm install 卡住
设国内源：
```bash
npm config set registry https://registry.npmmirror.com
```

### D. claude 命令找不到
```bash
source ~/.bashrc
which claude
```
应输出 `~/.nvm/versions/node/v20.../bin/claude`。

### E. 4 个 channel 全连不上
```bash
curl -I https://api.aipaibox.com/
curl -I https://www.micuapi.ai
curl -I https://main-new.codesuc.top/
curl -I https://byteswarm.ai/claude
```
看哪个返回 200，用那个。全 timeout 是网络问题。
