方法 B：手动 paste（如果方法 A 不行）
==========================================

★ 把下面 ★★★ 标记之间整段复制 ★★★
★ 不要包含 ★★★ 标记本身

★★★ 复制开始 ★★★

mkdir -p ~/.claude_zgc

cat > ~/.claude_zgc/settings.json << 'EOF'
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://www.micuapi.ai",
    "ANTHROPIC_AUTH_TOKEN": "sk-pRdgVnnj0EaaLhrradXQDClzPDeWMqJXPt78PAcYQWPBwiRU"
  },
  "model": "opus[1m]",
  "permissions": {"defaultMode": "bypassPermissions"},
  "effortLevel": "high",
  "fastMode": true,
  "skipDangerousModePermissionPrompt": true
}
EOF

if ! grep -q "claudezgc()" ~/.bashrc; then
    echo 'claudezgc() { _claude_p "$HOME/.claude_zgc" "zgc" "$@"; }' >> ~/.bashrc
fi

source ~/.bashrc
echo "✅ claudezgc 已加好"

★★★ 复制结束 ★★★

paste 完后跑：
claudezgc

==========================================
为什么需要 claudezgc
==========================================

- URL 和 micu 一样（micuapi.ai），但 key 不同
- 相当于 micu 的备用 key（micu 挂了或额度用完时切换）
- fastMode: true → 响应速度更快
- skipDangerousModePermissionPrompt: true → 跳过危险操作确认
